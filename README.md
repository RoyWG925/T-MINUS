# T-MINUS ⏱️

> 與全世界一起倒數每個重要時刻

一個精美的倒數計時網站,讓你追蹤並與全球用戶一起倒數每個值得期待的瞬間。

## ✨ 特色功能

- 🎯 **即時倒數計時** - 精確追蹤距離重要事件的剩餘時間
- 🌍 **全球共享** - 與世界各地的用戶一起期待同一個時刻
- 🎨 **精美視覺設計** - 太空主題的現代化介面,包含星空背景和動態效果
- 📱 **響應式設計** - 完美適配桌面、平板和手機裝置
- 🔥 **互動功能** - 為事件投票、追蹤和分享
- 🏷️ **分類篩選** - 支援運動、科技、娛樂、節日等多種分類

## 🎨 設計亮點

- 太空主題視覺風格,包含星空粒子效果
- 玻璃擬態 (Glassmorphism) 卡片設計
- 流暢的動畫過渡效果
- 軌道環動畫裝飾
- 滑鼠追蹤光暈效果
- 自訂顏色系統,不同分類有獨特的主題色

## 🚀 快速開始

### 直接使用

這是一個純前端專案,無需安裝任何依賴。只需:

1. 克隆或下載此專案
2. 在瀏覽器中打開 `index.html`

### 本地開發

```bash
# 使用任何本地伺服器工具,例如:
npx serve .

# 或使用 Python
python -m http.server 8000

# 或使用 VS Code 的 Live Server 擴充功能
```

## 🎯 主要功能

### 事件管理
- 建立自訂倒數事件
- 設定事件名稱、日期、分類和表情符號
- 查看事件的詳細倒數資訊

### 互動功能
- 🔥 為喜歡的事件投票
- 👥 追蹤感興趣的事件
- 🔗 分享事件連結
- 📊 查看事件的熱度指標

### 分類系統
- 🏃 運動 (Sports)
- 💻 科技 (Tech)
- 🎬 娛樂 (Entertainment)
- 🎉 節日 (Holiday)

## 🛠️ 技術棧

- **HTML5** - 語義化標記
- **CSS3** - 現代化樣式
  - CSS 變數
  - Flexbox & Grid 佈局
  - 動畫與過渡效果
  - 玻璃擬態設計
- **Vanilla JavaScript** - 無框架依賴
  - Canvas API (星空效果)
  - LocalStorage (資料持久化)
  - 日期時間處理
